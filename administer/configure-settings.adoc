= Configura le soglie di classificazione dei dati e la scansione degli accessi in AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le soglie di inattività e obsolescenza ti aiutano a individuare lo storage che puoi ottimizzare utilizzando AI Data Engine (AIDE). La scansione delle autorizzazioni e l'integrazione con Active Directory ti aiutano a individuare e comprendere i rischi di accesso. Impostale in modo che corrispondano alle policy di classificazione, conservazione e accesso ai dati della tua organizzazione.



[[before-you-begin]]
== Prima di iniziare

Devi avere il ruolo di amministratore di _AI Data Engine_.



[[what-is-cold-and-stale-data]]
== Che cosa sono i dati cold e stale?

Dati freddi:: File a cui non si è acceduto entro la soglia dei dati inattivi. I dati inattivi rappresentano una metrica chiave che la tua organizzazione può utilizzare per identificare lo storage che potrebbe essere ottimizzato in base alle politiche di conservazione e alle esigenze aziendali.
Dati obsoleti:: File che non sono stati modificati entro la soglia dei dati obsoleti. I dati obsoleti aiutano la tua organizzazione a identificare i file che non sono cambiati di recente e che puoi monitorare o gestire in base alle tue policy.


Queste soglie influiscono sui riepiloghi del dashboard, sui file visualizzati quando applichi i filtri per dati inattivi o obsoleti in Investigation e sui file a cui si applicano le policy. Scegli soglie che riflettano per quanto tempo i dati possono rimanere inutilizzati o invariati prima che la tua organizzazione li valuti. Una soglia più breve classifica un maggior numero di dati come inattivi o obsoleti, mentre una soglia più lunga restringe i risultati ai dati che sono rimasti inattivi più a lungo.


NOTE: I valori soglia predefiniti sono quelli predefiniti del prodotto forniti come punto di partenza. Non rappresentano periodi di conservazione previsti dalla legge, dalle normative o dagli standard di settore. Imposta soglie che rispecchino le politiche e i requisiti specifici della tua organizzazione.

Le modifiche alle soglie di freddo e di obsolescenza entrano in vigore dopo il completamento del ciclo di scansione successivo.



[[set-the-cold-data-threshold]]
== Imposta la soglia dei dati freddi

Definisci per quanto tempo i file possono rimanere senza essere consultati prima che la tua organizzazione ne valuti l'archiviazione, l'eliminazione o il monitoraggio. Puoi anche limitare la classificazione in base alle dimensioni del file ed escludere specifici tipi di file o percorsi.

.Passaggi
. Dall'interfaccia utente di AI Data Engine, seleziona *Configurazione* > *Impostazioni generali*.
. Espandi *Definizione dei dati freddi* e abilita la classificazione dei dati freddi se è disabilitata.
. In *Età basata su*, seleziona il timestamp che determina l'età: *Ultimo accesso* per identificare i file che non sono stati usati di recente, oppure *Ultima modifica* per identificare i file che non sono cambiati di recente.
. Imposta la *soglia di età a freddo*. Il valore predefinito è un anno.
. Imposta la *Dimensione minima del file (MiB)* e il *Limite massimo della dimensione del file (MiB)* per concentrarti sui file che ti interessano.
. Facoltativo: per escludere file specifici da questa classificazione, inserisci *Escludi tipi di file* e *Escludi percorsi*. Inserisci file e percorsi completi, separando più voci con virgole.
. Seleziona *Salva*.




[[set-the-stale-data-threshold]]
== Imposta la soglia dei dati obsoleti

Decidi per quanto tempo i file possono rimanere invariati prima che la tua organizzazione li esamini in base alle proprie politiche sul ciclo di vita dei dati. Puoi anche limitare la classificazione in base alle dimensioni del file ed escludere specifici tipi di file o percorsi.

.Passaggi
. Dall'interfaccia utente di AI Data Engine, seleziona *Configurazione* > *Impostazioni generali*.
. Espandi *Definizione dati obsoleti* e abilita la classificazione dei dati obsoleti se è disabilitata.
. In *Age based on*, seleziona il timestamp che determina l'età: *Last modified* o *Last accessed*.
. Imposta la *soglia di anzianità*. Il valore predefinito è tre anni.
. Imposta la *Dimensione minima del file (MiB)* e il *Limite massimo della dimensione del file (MiB)* per concentrarti sui file che ti interessano.
. Facoltativo: per escludere file specifici da questa classificazione, inserisci *Escludi tipi di file* e *Escludi percorsi*. Inserisci file e percorsi completi, separando più voci con virgole.
. Seleziona *Salva*.




[[find-access-risks-with-permission-scanning]]
== Individua i rischi di accesso tramite la scansione delle autorizzazioni

Attiva la scansione delle autorizzazioni quando devi trovare file e cartelle aperti a più persone di quante consentano le tue policy. Per esaminare i risultati, consulta link:../investigate/investigate-directories.html["Esamina le directory"].

.Passaggi
. Dall'interfaccia utente di AI Data Engine, seleziona *Configurazione* > *Impostazioni generali*.
. Espandi *Scansione delle autorizzazioni* e attiva l'interruttore.
+
Per interrompere la scansione delle autorizzazioni, disattiva l'interruttore.





[[show-user-and-group-names-with-active-directory]]
== Mostra i nomi di utenti e gruppi con Active Directory

Collega AI Data Engine ad Active Directory quando hai bisogno di visualizzare nomi utente e autorizzazioni, anziché ID numerici, mentre esamini i dati. Se il tuo ambiente utilizza NFS, puoi anche mappare gli ID utente numerici (UID) e gli ID di gruppo (GID) agli utenti e ai gruppi della directory.

Per i prerequisiti e i passaggi, consulta link:configure-ad-nfs.html["Configura la mappatura delle identità di Active Directory per NFS"].
