= Avvio rapido per AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Configura e avvia AI Data Engine (AIDE) distribuendo il servizio, collegando le tue origini dati e avviando la tua prima analisi. Puoi anche consentire ai client AI di cercare nei tuoi metadati tramite un accesso AI controllato.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"] link:../deploy/aide-requirements.html["Esamina i requisiti e seleziona un tipo di implementazione"]
[role="quick-margin-para"]
Esamina i requisiti e link:../deploy/deployment-overview.html["Scopri i tipi di implementazione"] per decidere se installare una distribuzione AIDE a nodo singolo o a più nodi.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"] link:../deploy/deployment-overview.html["Distribuisci AI Data Engine"]
[role="quick-margin-para"]
Distribuisci un link:../deploy/deploy-aide-single-node.html["Implementazione a nodo singolo di AIDE"] o un link:../deploy/deploy-aide-multi-node.html["Implementazione multi-nodo di AIDE"] da NetApp Console. La pagina di configurazione ti guida nella scelta del percorso di installazione e delle dimensioni della configurazione e nell'esecuzione del comando di installazione. Se il tuo host o cluster raggiunge Internet solo tramite un proxy, link:../deploy/configure-proxy.html["distribuisci con un proxy"] invece.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"] link:../data-sources/connect-data-source.html["Connetti una origine dati"]
[role="quick-margin-para"]
Collega un'origine dati per avviare la scansione. AI Data Engine cataloga i metadati delle origini dati a cui ti connetti.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"] link:../investigate/understand-dashboard.html["Esplora i tuoi dati"]
[role="quick-margin-para"]
Apri la dashboard per visualizzare informazioni sull'ottimizzazione dello storage oppure vai a link:../investigate/investigate-data.html["Indagine"] per cercare e filtrare direttamente i tuoi metadati.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinque"] link:../policies/create-policy.html["Crea una policy"]
[role="quick-margin-para"]
Salva i filtri di indagine come criterio per monitorare nel tempo i file che corrispondono agli stessi criteri. Puoi configurare un criterio per inviare una notifica, eliminare definitivamente i file corrispondenti o tenere traccia dei risultati.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Sei"] link:../mcp/quick-start-mcp.html["Opzionale: configura l'accesso governato all'AI"]
[role="quick-margin-para"]
Consenti ai client AI di cercare i metadati nelle raccolte che scegli. Gli utenti esperti possono cercare i metadati ed eseguire azioni sui dati.
