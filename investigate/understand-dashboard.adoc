= Valuta lo stato di salute dello storage con la dashboard di AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Prima di poter decidere cosa esaminare, devi comprendere lo stato del tuo storage. Quanto storage soddisfa le soglie di classificazione dei dati cold e stale della tua organizzazione e quali sistemi o proprietari detengono la maggior parte dei dati in queste categorie? Ad esempio, un amministratore dello storage che risponde a un avviso di capacità può vedere che una gran parte dello storage analizzato è costituita da dati cold, quindi può approfondire il sistema con l'impatto maggiore per iniziare subito a indagare.

Da NetApp Console, seleziona *AI data hub* > *AI Data Engine*. La dashboard si apre per impostazione predefinita. La dashboard organizza le informazioni in tre schede: *Ottimizzazione dello storage*, *Autorizzazioni* e *Dati strutturati*.

image::aide_mo_ga_overview_page.png[Panoramica della dashboard di AI Data Engine]



[[understand-how-much-storage-is-affected]]
== Scopri quanto storage è interessato

Scopri quanta parte dello storage scansionato è cold, obsoleta o esposta. Il pannello di riepilogo mostra l'entità del problema nell'intero ambiente scansionato:

* *Risorse dati*: Il numero di volumi, condivisioni e bucket attualmente analizzati.
* *Elementi scansionati*: Il numero totale di elementi indicizzati in tutte le risorse di dati scansionate.
* *Dati freddi*: storage a cui non si accede entro la soglia dei dati freddi (impostazione predefinita: un anno). La tua organizzazione può valutare questi dati in base alle tue policy di conservazione e governance.
* *Dati obsoleti*: Storage che non è cambiato entro la soglia dei dati obsoleti (impostazione predefinita: tre anni). I dati obsoleti potrebbero richiedere una revisione in base alle politiche sul ciclo di vita dei dati della tua organizzazione prima di decidere azioni come l'archiviazione o l'eliminazione.
* *Directory esposte*: Il numero di directory con impostazioni di accesso eccessivamente permissive e il relativo numero di file. Queste rappresentano un rischio di governance indipendente dal consumo di storage.


Le soglie di conservazione cold e stale riflettono le impostazioni che hai configurato, inclusi il timestamp e l'età che scegli. I valori predefiniti sono quelli del prodotto e non rappresentano i periodi di conservazione previsti dalla legge, dalla conformità o dagli standard di settore. Per modificarli, consulta link:../administer/configure-settings.html["Configura le soglie di classificazione dei dati e la scansione degli accessi"].

I filtri *Sistema* e *Tipo di sistema* controllano l'ambito del dashboard. Se un sistema storage non compare nell'elenco dei filtri, consulta link:../data-sources/connect-data-source.html["Connetti una origine dati"].

Il timestamp *Ultimo aggiornamento* indica quando i dati del dashboard sono stati aggiornati l'ultima volta. Seleziona *Aggiorna* per aggiornare il dashboard. Per verificare che i dati sottostanti siano aggiornati, consulta link:../data-sources/manage-data-sources.html#view-scan-status-and-details["Visualizza lo stato e i dettagli della scansione"].



[[identify-storage-optimization-opportunities]]
== Individua le opportunità di ottimizzazione dello storage

Scopri dove puoi recuperare più spazio di archiviazione. La scheda *Ottimizzazione dello spazio di archiviazione* include i seguenti grafici e tabelle:

* _Storage attivo rispetto a quello recuperabile_: Mostra la proporzione di dati attivi rispetto ai dati freddi e obsoleti in tutte le risorse scansionate. Un'elevata proporzione di dati freddi, obsoleti o duplicati potrebbe indicare una significativa opportunità di ottimizzazione dello storage.
* _Principali risorse dati per storage recuperabile_: Mostra le risorse dati con la maggiore capacità recuperabile.
* _Principali consumatori per spazio di archiviazione recuperabile_: mostra i proprietari dei dati, il loro spazio di archiviazione recuperabile e il numero di file.
* _Distribuzione delle dimensioni dei dati duplicati_: Mostra come i dati duplicati sono distribuiti nelle varie fasce dimensionali.
* _Età degli asset_: Mostra gli elementi in base all'età. Usa il menu a tendina per selezionare il criterio di timestamp per il grafico.
* _Tipi di file più comuni_: mostra i tipi di file più diffusi.


Utilizza il pannello di riepilogo e questi grafici per identificare e dare priorità alle opportunità di ottimizzazione dello storage:

* Concentrati sulle risorse che hanno la maggiore dimensione potenzialmente recuperabile, piuttosto che su quelle con la dimensione totale più elevata. Un piccolo sistema composto principalmente da dati obsoleti o inattivi potrebbe essere una risorsa migliore da valutare per prima rispetto a un grande sistema prevalentemente attivo.
* Cerca grandi concentrazioni di dati cold o obsoleti, anziché file isolati. Decine di terabyte di dati che soddisfano la tua soglia di obsolescenza su una singola risorsa meritano una valutazione. I file isolati potrebbero non richiedere alcun intervento.




[[review-permissions]]
== Rivedi le autorizzazioni

Individua le directory a cui dare priorità per una revisione delle autorizzazioni. La scheda *Autorizzazioni* mostra il grafico _Directory con autorizzazioni aperte_, che elenca i percorsi delle directory e il numero di file. Per visualizzare queste directory in dettaglio, consulta link:investigate-directories.html["Esamina le directory"]. Per controllare se AI Data Engine esegue la scansione delle autorizzazioni, consulta link:../administer/configure-settings.html["Configura le soglie di classificazione dei dati e la scansione degli accessi"].



[[explore-structured-data]]
== Esplora i dati strutturati

Visualizza quali schemi e tabelle sono presenti nei dati scansionati e confronta il numero di righe. La scheda *Dati strutturati* mostra la tabella _Riepilogo dei dati strutturati_, che elenca lo schema, il nome della tabella del database e il numero di righe. Per cercare e filtrare questi dati, consulta link:investigate-structured.html["Analizza i dati strutturati"].



[[move-from-the-dashboard-to-investigation]]
== Passa dalla dashboard all'indagine

Una volta identificata una risorsa o un proprietario che vale la pena esaminare, utilizza le tabelle nella scheda *Storage optimization* per passare direttamente ai dettagli.

La tabella _Top data resources by reclaimable storage_ elenca le risorse di storage sottoposte a scansione, classificate in base alla percentuale di dati duplicati o che soddisfano le soglie cold e stale della tua organizzazione. Usa la scheda link:investigate-unstructured.html["Non strutturato"] per identificare i file cold o stale, oppure la scheda link:investigate-directories.html["Directory"] per verificare l'esposizione delle autorizzazioni.

La tabella _Principali consumatori per spazio di archiviazione recuperabile_ mostra quali proprietari dei dati detengono dati potenzialmente recuperabili. Seleziona *Analizza* per aprire la link:investigate-unstructured.html["Indagine"] visualizzazione filtrata sui file di quel proprietario. Da lì, puoi esaminare i risultati, intervenire o salvarli come criterio.

Controllare la dashboard non archivia né elimina i dati né modifica i permessi della directory.
